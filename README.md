# Marha Passengers Transportation LLC

Marketing website and admin portal for Marha Passengers Transportation LLC — a UAE premium bus and vehicle rental service offering corporate transfers, airport shuttles, and event transportation.

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase

## Getting started

The only requirement is having Node.js & npm installed — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
# Step 1: Clone the repository.
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory.
cd MarhaPassengers

# Step 3: Install the necessary dependencies.
npm i

# Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev
```

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — build for production
- `npm run build:dev` — build in development mode
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint
